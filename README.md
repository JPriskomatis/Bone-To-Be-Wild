**Bone To Be Wild**

Play as a weak skelteon in a world filled with adventurers taking all the glory from you and try to prove yourself as a worthy adventurer. In give this RPG Medieval game you can cast spells, engage in combat and talk your way through with other NPCs while trying to reach the top of the adventure world.

**FEATURES**

*Branching Dialogue System using !Ink Scripting Language

*Abstraction & Interfaces for modularity for different kind of NPCs (civilians, guards, enemy), Quest System, Interaction System

*State Machine for AI combat (Idle, Chase, Attack, Hit, Death)

*Attackable entities breaks down into interfaces ISpellDamageable & ISwordDamageable

*Ability systems with modular code that allows to create new abilities by inhereting from a base class & an Interface

*Strategy Pattern to handle all kinds of different weapons (Like NormalSword and Icesword)
